# To-Do List Frontend (React + Vite)

This is the frontend application for the To-Do List project, built using React, Vite, and Axios for seamless communication with the backend API.

## Features
* View all tasks dynamically[cite: 3]
* Add new tasks with title and description[cite: 3]
* Mark tasks as complete/pending (status update)[cite: 3]
* Search tasks in real-time[cite: 3]
* Delete tasks[cite: 3]
